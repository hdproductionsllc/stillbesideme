Etsy connection

Enter one by hand All orders

Connect the Etsy shop once, then press a button whenever you want to bring new sales in. Pulling reads the paid orders Etsy is holding, takes the answers the buyer gave at checkout along with their photo, and creates an order sitting in awaiting review. It writes no poem, makes no proof, and sends nothing to the printer. That is still your review page, and nothing is printed until you record the buyer approving their proof. An order this cannot read cleanly is refused and left alone rather than guessed at, and you can always enter that one by hand.

The connection

Checking…

Before this will work, this address has to be registered as a callback URL in the Etsy developer portal, exactly as it reads here:

Register both this one and the local one you develop against (http://localhost:3001/admin/etsy/callback). Etsy compares the string character for character, so a missing slash or an http where there should be an https is enough to fail the exchange.

Connect the shop

Test the key first if this is the first time. It asks Etsy whether it recognises the key at all, which is the one thing worth knowing before approving the app, and it takes a second.

Disconnecting only forgets the permission. Orders already pulled in stay exactly where they are.

Orders

Check for orders reads what Etsy has and tells you what it would do, without creating anything. Pull orders in does it for real. Either way an order already in the system is left alone, so pressing the button twice is safe.
